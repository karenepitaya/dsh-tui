# Settings 模型与提供商列表修正 · 2026-09-08

> 后续已重做提供商管理表单与测试反馈并重新安装，当前结果见 [管理面板交付记录](SETTINGS-PROVIDER-MANAGEMENT-2026-09-08.md)。本页保留前一轮列表修正及其安装记录。

本轮处理用户对模型与提供商浮窗的截图反馈，延续 pi-tui + Orbs 实现。现有脏工作区保留，没有 commit / push。

## 用户可见变化

- 默认模型按提供商分组，每个模型只显示一次名称；同名提供商以内部 ID 补充区分，选择仍保存精确的 provider / model 身份。
- 删除默认模型和测试模型选择器的重复副标题。
- 快捷键移到独立屏幕底栏，浮窗内不再重复提示；窄屏按完整动作组换行。
- “当前默认”使用主题强调色，“已配置”使用主题成功色；光标移走后状态仍醒目。单色主题保留文字标记。
- 提供商目录限高滚动，不再随选项数量撑满屏幕。列表最多 18 个渲染行、面板最多 24 行，小窗口进一步收缩；底部自定义入口仍可到达。
- 首页添加入口移除内嵌快捷键，服务卡片不再重复显示配置状态。

没有改动提供商身份、认证流程或配置持久化协议。浏览不会发出模型请求，测试按钮仍只发送既有固定测试提示。

## 验收方式

重启 `tui`，进入 `/settings` → “模型与服务”：

1. 打开“新会话默认模型”，检查提供商分组、单次模型名称及“当前默认”标记。
2. 打开“添加提供商”，移动光标，检查已配置服务的颜色保持独立；滚到列表末尾打开自定义入口。
3. 进入一个服务并选择测试模型，检查没有重复副标题，快捷键位于屏幕底部。
4. 缩窄终端或切到 mono 主题，检查选中项、状态文字和返回提示仍可辨认。
